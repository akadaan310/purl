# PURL integrated God Seed implementation plan

> **For agentic workers:** use subagent-driven development for isolated tasks and root integration.

**Goal:** Deliver working locally verifiable PURL computation, discovery, continuity, IDE, durable worker adapters and all ten experiments, with truthful deployment gates.

**Architecture:** Preserve PURL/0.1; implement product modules behind independent versioned contracts. Supabase production repository and local development adapter share CAS transactions. API and worker use one portable image.

**Tech Stack:** Node standard library, browser JavaScript/CSS, PostgreSQL/Supabase REST/Storage, Docker, Playwright for browser evidence.

**Spec:** `docs/superpowers/specs/2026-10-18-godseed-design.md` and `reference/godseed/GODSEED.md`.

## Global constraints

- GET must not cause durable effects.
- Preserve historical projects and bundled evidence.
- No essential production state only inside an ephemeral container.
- No unrestricted public arbitrary code execution.
- Distinguish address, derivation, value, content, environment, build, execution and principal identity.
- Railway first; Oracle missing credentials must not block local implementation.

## Review focus

- Invalid/malformed AST, excessive repetitions and unsafe JS numeric values must reject predictably.
- Revoked grants, stale versions, forged principals and replayed idempotency keys must not authorize mutation.
- Interrupted jobs require lease recovery and persistent immutable results across restarts.
- Capsule copy must work for touch/keyboard and degrade gracefully when clipboard is denied.
- Projected operations must match enabledness/effects/successors on every enumerated fiber.
