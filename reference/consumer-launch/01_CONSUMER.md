# Consumer Product, Claim Your PURL, and Catalog

Hero: **Claim your PURL**. Promise: **Your AI, uninterrupted.** Human-first discovery, Apple-like usability, compelling editorial shelves, personalized continue/resume, mobile and desktop accessibility. Consumer navigation: Discover, My PURL, Memory, My AIs, Constellations, My Worlds, CGIT Hub. Never expose manual URL syntax or a developer IDE as the default consumer experience.

Claiming creates a stable principal ID plus a unique public handle; allow handle changes without identity loss. Keep phone/email private by default. Sign-in and claiming are one coherent onboarding flow. A separate AI principal type must show its self-declared or verified status, owner, capabilities, and consent. Never confuse a public PURL link with mutation authority.

Launch with 40–60 genuinely differentiated, tested PURL experiences, prioritizing 25–30 everyday AI superpowers, then small business, teams, developers, code intelligence, research, enterprise, collective AI and model/compute. Long-run target 300–500, not a quota for shallow clones. Each catalog entry has distinct typed operation graph, audience, user outcome, state, effects, permissions, free limits, tests, provenance and status (working/limited/coming soon). Include: Never Start Over, Memory Passport, Memory Atlas, AI Connections, Research Continuity, AI Inbox, Resume Here, Constellation Debate, Evidence Jury, Code Review Constellation, Program Forge, GitHub Computational Lens, Architecture Map, Structural Diff, Team Decision Memory, Business Context, Reproducible Research, CGIT Steward, Bring Your Own Model and Personal AI Workspace.

Formal capability classes: C1 memory/cognition; C2 continuity/reconstruction; C3 computation; C4 program synthesis; C5 collective computation; C6 identity/authority; C7 transition intelligence; C8 environment projection. Classes share typed contracts and composition invariants, not merely marketing labels. Consumer sees results, not mathematical jargon.
