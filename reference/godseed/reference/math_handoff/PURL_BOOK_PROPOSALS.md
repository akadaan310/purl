# Book and research-program proposals (no priority or novelty claims)

Only **two** candidates clear the present usefulness threshold, and neither currently justifies an independent claim to a new mathematical field. The first belongs primarily in existing work unless empirical evidence accumulates.

## Candidate A — *The Number: Representation, Distinction and Execution*

- **Form:** proposed Volume 0 / companion book to *Grammar in Numbers*, not a rebrand of its completed 351-page Edition 1.0.
- **Subject:** numeral systems, equivalence relative to observation, partial inverses, types, embeddings, spatial and temporal representation.
- **Prerequisites:** elementary discrete mathematics, introductory algebra, programming language basics.
- **Question:** what conditions make the "same value" survive changes of notation, compiler, machine and observer?
- **CGT/GiN relationship:** GiN provides numeral vs value and converse fibers; CGT supplies LTS, representation and resolution semantics; the existing *THE NUMBER* lane already covers seven layers and O1–O5 translation obligations.
- **PURL relationship:** grounds address/derivation/value/run namespaces; prevents semantic-hash misclaims.
- **Sample theorem (classical, not new):** a quotient transition exists iff the projection kernel is invariant under the operation (see independent finding 1).
- **Experiment:** encode the same integers in varied numeration grammars and compare semantic preservation, translation cost, converse solution class and parser behavior. Attempt to falsify O1–O5 with hidden state and machine narrowing.
- **Candidate 8-chapter outline:** (1) Distinction and observation; (2) Number vs numeral; (3) Canonical representations; (4) Translation failures; (5) Inverse operation fibers; (6) Spatial and temporal notation; (7) Machine semantics and limits; (8) A bridge into CGT and executable addresses.
- **Audience:** advanced students, software engineers, mathematical readers, programming-language researchers.
- **Publication gate:** audited references, explicit separation from existing GiN material, original pedagogical exercises, independent mathematical review, correct results and reproducible lab examples. No new theorem is required for an honest pedagogical volume.

## Candidate B — *Executable Addresses: Typed Programs, Capabilities and Recoverable Histories*

- **Form:** research note or methods paper **now**, a new book only if real deployments and comparative studies substantiate the method.
- **Subject:** operational semantics, algebra of effects, event-sourced execution, formal verification, capabilities, reproducibility.
- **Prerequisites:** type systems, automata/LTS, distributed systems, API security, elementary algebra.
- **Question:** can a URL-addressed manifest make a cross-platform mission operationally resumable while respecting authorization and replay correctness?
- **CGT/GiN relationship:** typed operational grammar from CGT; four evaluation/failure layers and identity distinctions from GiN; no new math assumed.
- **PURL relationship:** product-focused formalization and independent benchmark for the current reference PURL/0.1.
- **Sample proposition (standard composition law):** pure typed program composition is associative where type interfaces match. **Falsifiable engineering hypothesis:** versioned manifests and receipts reduce unlawful or incorrect session continuations against static DAG baseline under fixed task budgets.
- **Experiment:** preregister 30+ mixed missions across fresh Codex/Claude/ChatGPT-like clients with controlled tooling, three baselines and blind scoring; record token cost, errors, unauthorized acts, reproducibility and recovery.
- **Candidate 8-chapter outline:** (1) URL and program; (2) Typed mission grammar; (3) Effects and capability algebra; (4) Versioned state transitions; (5) Provenance and four identities; (6) Replay and nondeterminism; (7) Cross-session reconstruction; (8) Security and measured limits.
- **Audience:** protocol designers, PL researchers, agent infrastructure engineers.
- **Publication gate:** live implementation, security review, external comparison and open artifacts. If no measurable advantage appears, keep this as a technical report rather than a book.

## Not recommended now

A separate field named after one-bit transitions, cyclic `007` shifts, categorical PURLs, or SEURL's seven verbs does not currently meet the novelty/usability bar. The classical mathematics already explains what has been demonstrated. More books are not necessarily better than a rigorously updated CGT/GiN lineage.
